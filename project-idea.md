# Idea
- This project should be an alternative to stremio, chillio and fusion.
- We want to be able to support stremio addons
- Choose a suiting stack which work perfect on linux like QT with python for example or something else
- It should be memory efficient
- It should have a nice UI like the other clients with the following functionality:
    - Search
    - Sections: Movies and Series
    - Categories like: Top IMDB, ...
    - Load the movie/series posters/covers
    - Being able to select a sources
    - Being able to use Trakt
    - A video player which is compatible with most formats (HEVC, MKV, MP4, ...) and a nice UI for the player itself.
    - A subtitle selector for the video player
    - The player UI is very important that it looks nice.
    - Being able to continue watching

## Settings
- Being able to select the source of the metadata (TMDb or TVdb) for movies and series
- An option for spoilter protection (Blur content for unwatched episodes to avoid spoilers)
- Where to save progress (local or trakt)
- An about page

## UI
- Being able to select popular colorthemes like catpuccin, nord, ... (at least 15)
- Nice animations
